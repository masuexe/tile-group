# TileGroup 🪟

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

[English](README.md) | [简体中文](README_zh.md)

**轻量级、非侵入式的 Windows 按需窗口编组平铺工具（系统托盘常驻版）**

与其他“全局强制接管桌面”的平铺窗口管理器（如 GlazeWM、Komorebi）不同，**TileGroup** 完全不会打扰你日常使用 Windows：

- **非侵入式（按需编组）**：默认情况下，你的桌面和普通 Windows 没有任何区别，组外窗口完全不受影响，无需编写繁琐的黑名单规则。
- **按数量动态均分平铺**：随时按快捷键将任意窗口加入或移出“窗口组”，组内窗口自动按数量均分目标区域：
  - `1` 个窗口：铺满目标区域 (`1×1`)
  - `2` 个窗口：左右二等分 (`1×2`)
  - `3` 个窗口：左中右三列均分 (`1×3`)
  - `4` 个窗口：田字格四宫格 (`2×2`)
  - `5` 个及以上：自动计算 `M×N` 均分网格
- **窗口组全联动（同生共死）**：
  - **点击任意窗口唤醒整组**：当窗口组最小化或被其他全屏软件遮挡时，点击任务栏或桌面上的**组内任意一个窗口**，整个窗口组会自动同步唤醒并置顶并排显示。
  - **点击最小化同步收起**：最小化组内任意一个窗口，组内其他窗口会自动跟着一起最小化。
  - **关闭自动重排**：直接关闭组内某个窗口时，剩余窗口自动重新均分填满区域。
  - **移出自动还原**：将窗口移出组（`Alt + G`）时，自动恢复它加入组之前的原始尺寸和位置。
- **静默系统托盘运行**：无任务栏终端黑框，静默常驻右下角系统托盘。支持双击托盘图标隐藏/还原整组，右键菜单支持切换平铺区域、清空组、按需开关调试日志窗口、切换中英文以及退出。
- **像素级严丝合缝 & 极致轻量**：纯 Rust (`windows-sys`) 编写，支持 Per-Monitor V2 高分屏 DPI 感知与 Windows 10/11 DWM 隐形边框补偿。单文件 `.exe` 仅 **~156 KB**，内存占用仅 **~2 MB**。

## ⌨️ 默认快捷键

| 快捷键 | 功能说明 |
| :--- | :--- |
| **`Alt + G`** | 将当前激活窗口 **加入 / 移出** 窗口组，并立即自动均分平铺（移出时自动还原窗口原尺寸） |
| **`Alt + H`** | **一键隐藏（最小化）/ 还原** 整个窗口组（也可双击系统托盘图标） |
| **`Alt + S`** | **循环切换平铺区域**（全屏工作区 → 左半屏 → 右半屏 → 上半屏 → 下半屏）并立即重排 |
| **`Alt + T`** | 手动触发重新平铺（当用鼠标拖乱组内窗口后一键归位） |
| **`Alt + C`** | 清空窗口组（解散编组，所有窗口恢复自由状态） |
| **`Alt + L`** | 在 **中文 / 英文** 界面之间实时切换 (`ZH` / `EN`) |
| **`Alt + Q`** | 退出 TileGroup |

## 🚀 运行与命令行参数

直接双击 `tile-group.exe`（或默认英文界面的 `tile-group-en.exe`）即可静默在右下角系统托盘运行：

```powershell
# 自动检测系统语言并常驻系统托盘
tile-group.exe

# 强制使用英文界面
tile-group.exe --en

# 强制使用中文界面
tile-group.exe --zh

# 启动时默认打开日志终端窗口
tile-group.exe --console
```

## 🛠️ 从源码编译

```powershell
git clone https://github.com/masuexe/tile-group.git
cd tile-group
cargo build --release
```

编译后的单文件可执行程序位于 `target/release/tile-group.exe`。
