# TileGroup 🪟

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

[English](README.md) | [简体中文](README_zh.md)

**轻量级、非侵入式的 Windows 按需窗口编组平铺工具**

与其他“全局强制接管桌面”的平铺窗口管理器（如 GlazeWM、Komorebi）不同，**TileGroup** 完全不会打扰你日常使用 Windows：

- **非侵入式（按需编组）**：默认情况下，你的桌面和普通 Windows 没有任何区别，组外窗口完全不受影响，无需编写繁琐的黑名单规则。
- **按数量动态均分平铺**：随时按快捷键将任意窗口加入或移出“窗口组”，组内窗口自动按数量均分目标区域：
  - `1` 个窗口：铺满目标区域 (`1×1`)
  - `2` 个窗口：左右二等分 (`1×2`)
  - `3` 个窗口：左中右三列均分 (`1×3`)
  - `4` 个窗口：田字格四宫格 (`2×2`)
  - `5` 个及以上：自动计算 `M×N` 均分网格
- **关闭窗口自动重排**：如果直接关闭了组内的某个窗口，剩余窗口会自动重新均分填满区域。
- **移出自动还原**：将窗口移出组时，会自动恢复它加入组之前的原始尺寸和位置。
- **一键整组隐藏 / 还原**：将整个窗口组作为一个整体一键最小化隐藏，或一键原位唤醒置顶。
- **像素级严丝合缝 & 极致轻量**：纯 Rust (`windows-sys`) 编写，支持 Per-Monitor V2 高分屏 DPI 感知与 Windows 10/11 DWM 隐形边框补偿。单文件 `.exe` 仅 **~130 KB**，内存占用仅 **~2 MB**。

## ⌨️ 默认快捷键

| 快捷键 | 功能说明 |
| :--- | :--- |
| **`Alt + G`** | 将当前激活窗口 **加入 / 移出** 窗口组，并立即自动均分平铺（移出时自动还原窗口原尺寸） |
| **`Alt + H`** | **一键隐藏（最小化）/ 还原** 整个窗口组 |
| **`Alt + S`** | **循环切换平铺区域**（全屏工作区 → 左半屏 → 右半屏 → 上半屏 → 下半屏）并立即重排 |
| **`Alt + T`** | 手动触发重新平铺（当用鼠标拖乱组内窗口后一键归位） |
| **`Alt + C`** | 清空窗口组（解散编组，所有窗口恢复自由状态） |
| **`Alt + L`** | 在 **中文 / 英文** 界面之间实时切换 (`ZH` / `EN`) |
| **`Alt + Q`** | 退出 TileGroup |

## 🚀 运行与命令行参数

程序默认会根据你的 Windows 系统语言自动选择中文或英文界面，也可以通过参数指定或按 `Alt + L` 实时切换：

```powershell
# 自动检测系统语言
tile-group.exe

# 强制使用英文界面
tile-group.exe --en

# 强制使用中文界面
tile-group.exe --zh
```

## 🛠️ 从源码编译

```powershell
git clone https://github.com/masuexe/tile-group.git
cd tile-group
cargo build --release
```

编译后的单文件可执行程序位于 `target/release/tile-group.exe`。
